# 💡 Зал: 2-Канальный Выключатель и Zigbee 3.0 Мост (`zal-zigbee-2channel`)

Автономное решение для независимого беспроводного управления **двухканальным Zigbee 3.0 реле (Tuya TS0002)** с помощью энергоэффективного батарейного выключателя на базе связки **ESP32-C3** и **ESP32-C6**.

---

## ⚡ Аппаратное подключение

### 1. Выключатель в Зале (ESP32-C3)
- **Клавиша 1 (Линия 1):** `GPIO 2` замыкается на `GND`.
- **Клавиша 2 (Линия 2):** `GPIO 3` замыкается на `GND`.
- **Кнопка BOOT (`GPIO 9`):** отключена в коде для предотвращения случайных сбоев.
- **Подтяжка:** внутренний Pull-Up зафиксирован аппаратно через `gpio_hold_en()` и сохраняется во время сна.
- **Потребление в покое:** **~5 мкА** (ресурс батарейки CR2032 / аккумулятора — **1.5–3 года**).

### 2. Хаб-мост (ESP32-C6)
- **Адресный светодиод WS2812:** `GPIO 8`
  - *Янтарное мигание:* открыто окно сопряжения Zigbee (180 сек).
  - *Синяя вспышка:* переключение Линии 1.
  - *Зеленая вспышка:* переключение Линии 2.
- **Локальная кнопка BOOT (`GPIO 9`):**
  - *1 клик:* переключить Линию 1.
  - *2 клика:* переключить Линию 2.
  - *Удержание (>2.5 сек):* повторно открыть окно сопряжения Zigbee.

## 🛠 Ключевые инженерные решения

### 1. Расцепление спаренных каналов Tuya (Relay Uncoupling)
Стандартные двухканальные реле Tuya (`TS0002` / `_TZ3000_...`) с завода физически спарены: включение одного канала синхронно включает второй. В прошивке C6 реализован 5-шаговый сиквенс расцепления:
1. `Read Attribute 0xFF` (базовый опрос производителя).
2. Запись служебного атрибута расцепления `0xFFDE = 0x0D` (длина 2 байта, значение `0x0001`).
3. Технологическая пауза 2.6 секунды на перезагрузку внутреннего контроллера реле.
4. Отправка команды разблокировки `0xF0` на Конечную Точку 1.
5. Привязка ZDO Bind кластера On/Off (`0x0006`) раздельно:
   - **Линия 1 ➔ EP 1**
   - **Линия 2 ➔ EP 2**

### 2. Радиоканал Coexistence и Burst 80 мс
В ESP32-C6 единый радиотракт 2.4 ГГц разделяет эфир между Zigbee и Wi-Fi по времени (TDM).
- При нажатии клавиши ESP32-C3 передаёт серию из **8 импульсов с шагом 10 мс** (суммарно **80 мс Burst**) на максимальной мощности **+21 dBm**.
- Это на 100% перекрывает окно прослушивания Zigbee, гарантируя приём пакета с 1-го нажатия.
- На C6 работает дедупликатор с окном **350 мс**, исключающий повторные щелчки реле.
- Измеренный уровень RSSI: **`-65...-73 dBm`** (отличное качество связи).

### 3. Конфигуратор Kconfig на русском языке и вырезание неиспользуемого кода
Обе прошивки содержат меню `idf.py menuconfig`, полностью переведённое на русский язык:
- Выборочное отключение конечных точек (Линия 1 / Линия 2).
- Отключение процедуры расцепления Tuya для обычных реле.
- Отключение адресного светодиода или локальных кнопок.
- Вырезание информационных логов `ESP_LOGI` из секции `.rodata` Flash.
- **Экономия Flash-памяти: более 38 КБайт**.

## 🚀 Сборка и прошивка (ESP-IDF 6.1)

### Сборка и прошивка ESP32-C6 (Хаб):
```powershell
cd c6-coordinator-hub
idf.py set-target esp32c6
idf.py build
idf.py -p COM36 flash
```

### Сборка и прошивка ESP32-C3 (Пульт):
```powershell
cd c3-battery-switch
idf.py set-target esp32c3
idf.py build
idf.py -p COM11 flash
```
